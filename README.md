# BajaAudio

App sencilla para Android: pegas un link de YouTube (o compartes el video desde YouTube → **BajaAudio**) y descarga el audio en **MP3** a la carpeta **Música/BajaAudio** del teléfono. Luego, con un toque, lo puedes guardar en Google Drive.

## Descargar

📲 **[Descargar BajaAudio.apk](../../releases/latest/download/BajaAudio.apk)**

Requiere Android 10 o superior.

Usa [yt-dlp](https://github.com/yt-dlp/yt-dlp) vía [youtubedl-android](https://github.com/JunkFood02/youtubedl-android), y se actualiza solo una vez al día.
Úsala solo con contenido que tengas derecho a descargar.
